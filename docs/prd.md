# PleosMate 제품 요구사항(PRD)

## 1. 제품 비전

**차와 함께한 평범한 하루가, 나를 기다리는 동료의 성장과 우리의 추억으로 남는다.**

PleosMate는 Pleos Connect 차량에서 사용하는 동료 펫 서비스다. 차량 기능을 알아보고, 도착한 동네를 발견하고, 하루의 기억을 남기는 행동을 펫의 성장으로 연결한다. 출발 전과 도착 후의 짧은 주차 시간이 사용자와 차 사이에 애착이 쌓이는 시간이 되도록 한다.

## 2. 해결하려는 문제

차량은 매일 사용하는 개인 공간이지만, 사용 경험은 운전과 기능 조작에 집중되어 있다. 익숙하지 않은 차량 기능은 설명을 읽고 끝나기 쉽고, 반복되는 출퇴근이나 작은 나들이는 별다른 기록 없이 지나간다. 차량을 오래 사용해도 사용자의 취향과 경험이 화면에 쌓이는 느낌은 약하다.

다음 세 가지를 제품 가설로 둔다.

- 차량 기능을 짧은 체험과 긍정적인 반응으로 안내하면 사용자가 기능을 알아보기 쉬워진다.
- 실제 방문한 곳과 개인 기억이 펫 성장에 연결되면 일상 이동에도 기념할 이유가 생긴다.
- 함께한 경험을 기억하는 동료가 있으면 다음 주차 시간에 앱을 다시 열 동기가 생긴다.

이 가설은 사용자 관찰과 시제품 평가로 확인한다.

## 3. 대상 사용자와 사용 상황

| 대상 | 사용 상황 | 기대하는 가치 |
| --- | --- | --- |
| 차량 기능에 익숙해지고 싶은 운전자 | 출발 준비를 마친 뒤 잠시 주차 중 | 어려운 설명 없이 내 차를 하나씩 알아보기 |
| 반복되는 일상에 작은 즐거움을 원하는 운전자 | 출퇴근 도착 후, 탑승자를 기다리는 시간 | 짧은 성취와 나를 반기는 동료 |
| 방문 장소를 기념하고 싶은 운전자 | 나들이나 여행 목적지에 도착한 뒤 | 방문한 동네와 기억을 수집으로 남기기 |

핵심 사용자는 운전자이며 동승자와 함께 볼 수 있는 경험도 고려한다. 집중이 필요한 운전 중에는 입력·수집·미션 수행을 요구하지 않는다.

## 4. 제품 목표와 설계 원칙

첫 사용에서 동료와 관계를 맺고 하나의 성취를 경험하게 한다. 재방문에서는 성장한 모습과 쌓인 기록을 통해 이전 사용이 이어지고 있음을 느끼게 한다.

| 원칙 | 설계에 반영할 내용 |
| --- | --- |
| 주차 시간에 맞는 짧은 경험 | 하나의 미션이나 기억 저장을 짧은 흐름으로 끝낼 수 있게 구성 |
| 실제 경험에 근거한 성취 | 차량 상태·현재 위치·사용자가 남긴 기억에 맞는 보상 제공 |
| 반복 방문의 의미 | 같은 동네의 재방문도 다른 날의 조각으로 남김 |
| 조작과 이동 부담 최소화 | 추가 운전, 불필요한 기능 작동, 조작 횟수 경쟁을 유도하지 않음 |
| 믿을 수 있는 기록 | 저장된 성장과 기억이 재실행 후에도 이어지고, 불확실한 값은 설명 |
| 빠른 시작 | 첫 버전은 회원가입 없이 차량 안에서 시작하고 기록 보관 범위를 안내 |

## 5. 핵심 사용자 여정

### 첫 만남

앱 실행 → 마음에 드는 동료 선택 → 이름 정하기 → 홈에서 동료 만나기 → 주차 상태에서 첫 미션 수행 → 동료 반응과 첫 성장 확인.

처음부터 모든 기능을 설명하지 않는다. 동료와 첫 성취를 경험한 뒤 여행·도감·꾸미기로 관심을 넓힌다.

### 일상 재방문

홈에서 동료와 성장 상태 확인 → 오늘 할 수 있는 활동 선택 → 차량 상태 확인 또는 한마디 기록 → 보상 확인 → 도감에서 이전 기억 돌아보기.

완료한 활동은 반복 설명과 보상 요청을 줄이고, 다른 날 다시 할 수 있는 활동은 다음 기회를 이해할 수 있게 표시한다.

### 여행과 재방문

목적지 도착·주차 → 여행 지도에서 현재 동네 확인 → 첫 조각 수집 → 방문 지역과 동료 성장 확인 → 다른 날 같은 동네에서 다음 조각 수집.

지도 탐색은 방문 계획과 수집 현황 확인에 사용한다. 실제 조각 획득은 현재 위치를 확인한 뒤 진행한다.

### 기억 남기기

주차 후 관찰된 여정 또는 직접 기록 선택 → 주제와 짧은 메모 작성 → 저장 → 도감에서 열람·수정·삭제.

측정한 이동 정보와 직접 작성한 기억을 구분해 보여준다. 관찰하지 못한 구간을 임의로 보충하지 않는다.

## 6. 첫 버전의 기능 범위

| 영역 | 요구사항 | 사용자에게 제공할 결과 |
| --- | --- | --- |
| 동료 선택 | 6종 동료와 이름 선택, 변경 지원 | 취향에 맞는 동료와 지속적인 관계 |
| 홈 | 동료 반응, 성장 상태, 다음 활동 안내 | 현재 상태와 할 일을 빠르게 이해 |
| 미션 | 바람·도어 확인, 차량 기능 알아보기, 장소·목적지·한마디·첫 인사 | 차량과 하루를 알아가는 작은 성취 |
| 여행 | 지역 지도 탐색, 현재 동네 확인, 동네별 조각 수집 | 방문과 재방문이 쌓이는 여행 지도 |
| 성장·꾸미기 | XP와 레벨, 성장 외형, 해금된 소품·공간 | 성취에 따른 시각적 변화와 자기표현 |
| 도감·기억 | 배지, 성장 이야기, 경험·여정 기록 열람 | 함께한 시간을 돌아보는 공간 |
| 설정 | 반응 음성, 기능 안내, 보관 안내, 전체 초기화 | 사용자가 경험과 기록을 관리 |

계정·클라우드 동기화, 친구·랭킹, 결제·쿠폰·제휴 정산은 후속 검토 범위로 둔다. 첫 버전은 차량 안의 동료 경험과 기록의 완결성에 집중한다.

## 7. 상세 제품 정책

### 미션

차량 기능 알아보기는 누적 주행거리, 타이어 저압 기준값, 배터리 잔량, 실내 조명·온도, 와이퍼, 좌석 착석, 브레이크 페달, 방향 지시등, 미러 열선 상태를 대상으로 한다. 차량이 제공하는 정보만 안내하며, 미지원 기능은 이유를 표시하고 다른 활동으로 이동할 수 있게 한다.

미션 설명은 무엇을 확인하는지와 무엇이 완료 조건인지를 먼저 알려준다. 타이어 저압 기준값을 실제 공기압 진단으로 오해하게 하거나, 상태 확인을 위해 추가 운전·기능 작동을 요구해서는 안 된다.

### 보상·성장

보상은 첫 경험의 동기를 주고 일상 재방문을 돕도록 설계한다. 첫 경험은 눈에 띄게 보상하되 같은 행동을 연속 반복해 성장시키는 구조는 피한다.

| 활동 | 보상 정책 |
| --- | --- |
| 첫 바람 경험 | 최초 10 XP |
| 다른 날의 바람 경험 | 하루 2 XP |
| 도어 확인 | 하루 5 XP, 한 주에 3일 달성하면 15 XP 추가 |
| 차량 기능 알아보기 | 기능별 첫 완료 5 XP |
| 장소 / 목적지 / 한마디 | 각각 하루 5 / 10 / 5 XP |
| 첫 인사 | 최초 5 XP |
| 동네 조각 | 동네별 하루 1개, 조각당 5 XP |
| 첫 시·도 발견 | 해당 시·도 첫 방문에 5 XP 추가 |

초기 레벨은 10·30·60 XP에서 상승하고 이후 50 XP마다 상승하도록 설계한다. 동료를 바꾸어도 함께 쌓은 성장은 유지한다. 보상 수치는 사용성 평가에서 성취감과 피로도를 함께 살펴 조정한다.

### 동네 조각

전국 동네를 탐험 단위로 삼고 시·도 → 시·군·구 → 동네 순서로 지도를 탐색한다. 같은 동네는 서로 다른 날 최대 세 조각을 모으며, 각 조각은 ‘첫 만남’, ‘다시 만남’, ‘소중한 추억’이라는 관계의 깊이를 표현한다.

위치 확인 결과가 오래됐거나 경계가 불확실하면 재확인을 안내한다. 정확한 동네를 판정할 수 없을 때 임의의 조각을 지급하지 않는다. 작은 동네·섬·경계 인접 지역도 서비스 범위 검토에 포함하며, 수집 가능한 범위를 사용자에게 명확하게 알린다.

### 기억과 데이터

짧은 기록을 위해 주제는 30자, 메모는 200자 이내로 구성한다. 초안을 이어 쓸 수 있게 하고 저장한 기억은 수정·삭제할 수 있게 한다. 측정 거리와 사용자가 쓴 글은 구분한다.

첫 버전은 차량 내 로컬 보관을 기본으로 한다. 같은 차량 사용자가 기록을 볼 수 있다는 점과 앱 삭제·초기화 시 기록이 사라진다는 점을 안내한다. 동네 수집에는 필요한 동네·조각·날짜만 보관하며 지속적인 위치 경로 수집을 요구하지 않는다.

| ID | 요구사항 | 수용 기준 |

| Q-01 | 주차 상태에서 안전하게 활동 | 시작·완료 시 주차 및 화면 사용 허용 여부 확인, 주행 전환 시 진행·보상 중단 |
| Q-02 | 정확한 완료 판정 | 권한 거부·미지원·유효하지 않은 차량 값은 성공으로 처리하지 않음 |
| Q-03 | 중복 없는 보상 | 연속 탭·재진입·재실행에도 같은 완료에 보상 한 번만 지급 |

| Q-05 | 지속되는 성장 | 저장 성공 후 재실행·업데이트에도 확정된 성장과 기록 유지 |
| Q-06 | 실패와 취소의 일관성 | 저장 실패를 성공으로 표시하지 않으며 취소한 작업의 결과를 나중에 반영하지 않음 |
| Q-07 | 이해 가능한 제한 안내 | 주행 제한·권한·연결·위치 불확실성을 구분하고 다음 행동 제시 |
| Q-08 | 기록 관리의 예측 가능성 | 기억 삭제와 전체 초기화의 범위를 설명하고 전체 삭제 전에 확인 |

## 9. 성공 지표와 검증 계획

| 지표 | 정의 | 확인 목적 |
| --- | --- | --- |
| 첫 성공률 | 첫 사용 세션에서 한 활동을 저장한 사용자 비율 | 온보딩과 첫 활동 이해도 |
| 첫 성공 소요시간 | 동료 선택부터 첫 완료까지 걸린 시간 | 짧은 주차 시간과의 적합성 |
| 동네 수집 성공률 | 위치 확인 요청 대비 정상 수집 완료 비율 | 지역 판정과 안내 품질 |
| D7 재방문 | 첫 사용 7일 후 다시 사용한 비율 | 동료와 기록의 재방문 동기 |
| 기억 열람·추가 작성 | 기록을 다시 열거나 새 기억을 남기는 행동 | 누적 기록의 가치 |

시제품 사용 관찰에서 기준값을 확보하고 출시 목표를 정한다. 활동 완료 이유와 이탈 이유를 인터뷰로 함께 확인한다. 이동 거리나 기능 조작 횟수 증가는 제품의 성과 지표로 삼지 않는다.

## 10. 후속 확장: 리워드와 B2B 제휴

동료와 성장 경험을 기반으로 재방문이 형성되면, 미션과 활동에서 얻는 성취를 주유비 할인·충전 할인·차량 관리 쿠폰 등 실제 차량 생활의 혜택으로 확장한다. 사용자는 일상에서 얻은 리워드로 유지비 부담을 낮추고, 제휴사는 고객의 방문과 재이용을 유도할 수 있도록 설계한다.

우선 제휴 대상은 주유소·충전 사업자·정비 및 세차 사업자이며, 이후 완성차·모빌리티 플랫폼의 고객 혜택 프로그램과 연계하는 B2B 모델을 검토한다. 참여 기업이 캠페인과 혜택을 제공하고 PleosMate가 사용자 활동과 혜택 사용을 연결하는 구조를 목표로 한다.

첫 단계에서는 성장 XP와 제휴 리워드를 구분하고, 지급·사용 조건과 유효기간을 명확하게 안내한다. 추가 주행 거리나 연료 소비량에 비례해 리워드를 지급하지 않으며, 제휴 범위와 비용 분담이 합의된 혜택부터 제공한다.
