# PleosMate 검증 범위와 잔여 위험

기준일: 2026-11-13. 현재 코드 검토와 앞선 ADB 검증 로그를 요약했다. 이번 문서 작성에서 전체 테스트나 실차 시험을 새로 실행하지 않았다.

## 1. 환경과 근거

Pleos Connect v2.1.0 AVD, Android 14(API 34), arm64, 2560×1440, 160 dpi에서 탐험 수집 흐름을 실행했다. 에뮬레이터 GPS와 날짜를 설정한 뒤 실제 앱 UI 버튼을 조작하고 UIAutomator 문구로 결과를 확인했다. 실물 차량 주행이나 물리 GPS 검증과는 범위가 다르다.

이번 작성 시 확인한 원본은 로컬 `/tmp/pleos-exploration-verification/`의 `events.jsonl`, `status.json`, `phase2-results.json`, `persistence-result.json`이다. 임시 경로는 영구 증빙이 아니므로 이 문서에 핵심 수치를 남긴다. 현재 회귀 테스트의 실행 결과로 대신 사용하지 않는다.

초기 수집 전 기존 조각 1개가 있었기 때문에 첫 조각 검증 3,475건 뒤 표시 합계가 3,476개였고, 추가 32개 뒤 3,508개가 됐다. 이 합계는 전국 모든 조각 수집 완료를 뜻하지 않는다.

첫 수집을 재개한 뒤 `processed_this_run` 값은 3,010이었다. 전체 완료 수는 이벤트 누적과 `ready_neighborhoods=3475`를 기준으로 집계했으며 재개 이후 수치를 전국 완료 수로 오해하지 않는다.

재시작 직후 홈 화면을 조회한 최초 확인은 실패했으나 여행 탭으로 이동해 동네를 조회한 후 3/3 보존을 확인했다. 최종 영속 확인 결과는 성공이다.

## 3. 현재 APK 확인

로컬 `apk/zumfriend_pleosmate_release.apk`는 109,635,114바이트이며 패키지 `com.pleos.mate`, versionCode 1, versionName 1.0이다. Android apksigner의 v2 서명 검증을 통과했다.

SHA-256: `1c55dd51173ec4af7a46481877ba5aee46f5814d2a7c62a02382c8fcac8ef2ac`

이는 해당 파일의 서명·식별 결과다. 최종 소스 커밋과 동일한 소스에서 만들어졌다는 재현 빌드 증명이나 전체 release 기능 검증을 뜻하지 않는다. 최종 제출 시 새 빌드 여부를 결정하고 소스·APK·태그의 대응을 기록해야 한다. 100MB 초과 파일이므로 GitHub Release 첨부가 필요하며 업로드 완료는 아직 확인되지 않았다.

## 4. 남은 위험과 확인 방법

- 경계·섬·좁은 동네: 84개 사례를 동네별로 분류하고 실제 접근 가능한 유효 지점에서 확인한다.
- 시간 신뢰: 날짜 변경으로 다음 슬롯을 수집할 수 있다. 현재 로컬 달력 규칙과 금전성 보상용 신뢰 요구를 구분한다.
- 차량 지원 범위: 창문 값 범위 등 AVD 가정이 있다. 실차의 속성·단위·권한·UX 제한을 확인한다.
- 비동기 경합: 주행 전환·권한 변경·화면 이탈·중복 탭·저장 실패를 지급 직전까지 확인한다.
- 저장 지속성: 대표 재시작 성공 외에도 업데이트·손상·디스크 부족·초안·초기화 시나리오를 검증한다.
- 과거 테스트 실패: `architecture.md`에는 2026-11-01 당시 `PetCollectionTest.reunionNeverInventsOrRestoresDeletedMemories` 실패가 기록돼 있다. 지금도 실패하는지 재실행하지 않았으므로 현재 결과는 미확인이다.
- 사용성과 성능: 첫 성공 시간, 반응 지연, 장시간 안정성, 배터리·메모리 수치를 새로 측정하지 않았다.

## 5. 테스트 자산과 실제 통과의 구분

`app/src/test`에는 미션 정책·성장·여정·탐색 등의 테스트가 있고 `app/src/androidTest`에는 탐험 계층·렌더·저장·수명주기 테스트가 있다. 파일이 존재한다는 사실은 현재 통과 결과가 아니다. 배포 전 실행 명령·환경·시각·결과를 별도 기록한다.

현재 확인된 범위를 넘어 “모든 미션·모든 동네·모든 조각·모든 차량을 검증 완료”로 표현하지 않는다.
