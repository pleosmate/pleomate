# PleosMate 문서

제품 기획에서 요구사항과 개발 방향을 정하고, 설계·검증 문서로 구현 방법과 결과를 관리한다.

| 문서 | 역할 |
| --- | --- |
| [제품 요구사항(PRD)](prd.md) | 사용자 문제, 제품 비전, 핵심 여정, 기능 정책과 수용 기준 |
| [개발 계획](development-plan.md) | 경험 설계부터 구현·검증·출시까지의 단계와 완료 기준 |
| [경쟁력·사업 전략](competitive-analysis.md) | 포지셔닝, 차별화, 사업 모델과 검증할 가설 |
| [Android 아키텍처](architecture.md) | 구현 구조와 상태·저장·SDK 데이터 흐름 |
| [검증 범위와 잔여 위험](verification-status.md) | 실행 결과, 시험 범위, 미해결 항목과 APK 상태 |

PRD의 요구사항과 개발 계획의 완료 기준을 기준으로 설계·개발을 진행한다. 기능의 실제 구현 상태와 시험 결과는 아키텍처·검증 문서에서 확인한다. 날짜가 붙은 실행 기록은 해당 시점과 환경의 결과로 해석한다.
