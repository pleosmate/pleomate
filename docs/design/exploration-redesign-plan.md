# 동료·탐험·여행책 개편 계획

기준일: 2026-11-05. 작업 전 보존 커밋: `400086d`.
상태: 기획·와이어프레임 초안. 제품 화면·서버 기능 구현 전.

## 제품 방향

차의 동료와 일상을 쌓고 새로운 곳을 발견하며 경험을 나눈다. 펫에 대한 애착, 탐험·기념품 수집, 장소 발견의 실용성을 연결한다. 배송·음성방은 범위에서 제외한다. Gleo는 별도 후속이다.

## 작업 순서와 완료 기준

1. 화면 구조: 동료·탐험·여행책 3개 주요 공간으로 정리. 각 기능에 진입·완료·다음 행동이 정의되면 완료.
2. 시안: 캐릭터 중심 홈과 지도·지역 상세·초대장·여행책을 클릭형 와이어프레임으로 연결. 현재는 실제 데이터가 아닌 명시적 예시를 사용한다. 가로 차량 화면에서 비교한 뒤 미술 방향을 확정.
3. Compose UI: 확정된 구조에 기존 미션·기억·도감·꾸미기 기능을 연결. 기존 선택·성장·기록 보존 및 주차 제한을 확인.
4. 개인 탐험: 위치 동의를 받아 저장한 방문을 지역으로 연결하고 첫 기념품 획득. 지역 ID·방문 검증·중복 지급 정책·위치 보관 범위를 먼저 확정. 수동 기록과 방문 인증을 구분.
5. 초대장·코스: 제한된 실제 장소 데이터로 시작. 장소 공개·주차·비용·걷기 조건을 확인한 뒤 출발 결정. 최신성 확인과 내비 연결 실패 동작 필요.
6. 공유·공동 지도: 먼저 Android 공유 카드, 계정·서버 동기화 이후 가족 공동 지도. 코스·팁 작성자 및 적용 조건·관리 정책은 소셜 출시 전에 설계.

## 화면 배치

- 동료: 펫 중심, 실제 기억으로 재회, 오늘의 제안 1개. 차량 미션과 한마디 작성은 즉시 접근. 꾸미기·동료 변경은 동료 메뉴.
- 탐험: 내 지도/함께 지도 전환. 그림 지도는 성취 표현, 위치 확인은 실제 지도. 지역 선택 시 기념품·기억·코스 상세. 초대장도 여기서 열람.
- 여행책: 기억·기념품·배지·저장 코스. 주간 이야기와 공유 카드. XP를 중복 저장하지 않고 기존 성장 기록에서 배지 계산.
- 설정: 동료 메뉴에서 접근. 개발 도구는 debug 전용 유지.

## 시안 유의점

`exploration-wireframe.html`은 구조 검토용이며 실제 방문·추천·공동 지도·보상 기능이 아니다. 숫자·지역·코스는 모두 예시. 배경 없는 홈을 기본으로 유지하고, 현재 배경 이미지 에셋은 재도입하지 않는다.

## 확인할 사용자 반응

펫을 만나는 즐거움, 다음 지역/기념품에 대한 기대, 기존 추억을 다시 보는 가치, 초대장 이후 방문·저장으로 이어지는지 확인한다. 출석 손실·펫 벌점·추가 주행량 경쟁은 도입하지 않는다.

## 실제 앱 창 크기 대응 착수

앱 사용 가능 너비 600dp 미만에서 좌우 여백 16dp, 홈 제목 축소, 펫 카드 340dp로 조정한다. 넓은 창은 32dp 여백과 420dp 펫 카드, 최대 콘텐츠 너비 1200dp를 사용한다. XP는 세로 정보 흐름으로 배치한다. 하단 탐색은 480dp 미만에서 항목 44dp와 축소 간격, 동료 아이콘 60dp를 사용한다. 화면 비율을 추정하지 않고 BoxWithConstraints로 받은 너비를 사용한다. 아직 1/3·2/3 실행 화면 전환 및 전체 기능의 가로 넘침 검증을 완료한 것은 아니다. 탐험·여행책의 새 제품 기능과 시안의 밝은 팔레트는 별도 구현 단계다.

### 2026-11-05 실제 차량 창 검증 후 보정

HTML 외형 복제보다 실제 차량 창에서의 사용성을 우선한다. 현재 색상과 배경 없는 펫을 유지한다.
- 홈 콘텐츠 폭 840dp 이상: 펫과 미션·기억을 두 열로 배치. 그 미만은 한 열.
- 펫 영역은 창 높이를 반영하며 좁은 창 240–400dp, 넓은 창 240–620dp 범위로 제한.
- 홈 최대 콘텐츠 폭은 1600dp, 나머지 화면은 1200dp.
- 작은 하단 탭도 너비 48dp 확보. 동료 선택 버튼에 접근성 이름 추가.
- 전역 터치 효과 차단을 제거해 기본 버튼과 탭에 눌림 피드백 복구. 별도로 indication=null인 펫 등은 기존 동작 유지.
- Debug 빌드 및 단위 테스트 통과. Computer Use로 Pleos 2/3 → 1/3 전환 및 좁은 창 미션 탭 이동 확인.
- 이번 변경은 홈·공통 탐색의 사용성 개선이며, 탐험/여행책 기능 구현이나 전체 제품 배포 승인 검증을 의미하지 않는다.
