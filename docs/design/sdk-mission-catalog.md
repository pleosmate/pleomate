# Pleos SDK 기반 미션 카탈로그

- 최초 작성: 2026-10-27 · 최신 통합 상태: 2026-10-31
- 상태: 미션 조건·보상·기존 확인 기록을 관리한다. 최근 실행 결과와 미완료 검증은 문서 끝의 현황을 우선한다. AVD 지원을 전 차종 실차 지원으로 일반화하지 않는다.
- 근거: [공식 SDK Overview](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/) · [Vehicle SDK 도메인 안내](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/Vehicle/intro) · Vehicle SDK 2.3.2 소스

## 미션 주기

| 주기 | 미션 | 완료·중복 기준 | 보상 | 연결 상태 |
| --- | --- | --- | --- | --- |
| 일일 | 운전석 문 닫힘 확인 | 앱이 주차·UX 허용 상태에 들어오면 운전석(앞좌석 왼쪽) Door position을 자동 조회. 닫힘이면 현지 날짜당 1회 | +5 XP | Door position SDK 읽기·자동 보상 확인. 잠금 속성은 AVD에서 `ERROR_NOT_SUPPORTED_PROPERTY` |
| 주간 | 차와 함께한 한 주 | 해당 ISO 주간에 서로 다른 3일의 일일 문단속 미션 완료 시 1회 | +15 XP | 일일 미션 기록에서 누적 |
| 한 번만 | 바람 느끼기 | 앱 활성 중 앞좌석 왼쪽 Window 열림 값을 자동 수신. 주행 중 감지한 경우 XP는 안전한 주차·UX 허용 상태에서 저장 | +10 XP | AVD에서 열림 신호·자동 보상 확인 |
| 주간 후보 | 함께한 이동 돌아보기 | 유효한 Odometer 구간 확보 후 사용자 확인 | 보상 보류 | AVD의 current trip distance capability 오류 원인 확인 전 잠금 |

일일 보상은 기기 현지 날짜, 주간 보상은 ISO week-year와 week number를 사용한다. 일일 확인 날짜를 영속 저장하므로 같은 날 재시도·콜백 중복으로 XP가 늘지 않는다. 주간 보너스는 3개의 서로 다른 날짜가 필요하며 연속 출석은 요구하지 않는다. 한 번만 미션은 기존 최초 완료 기록으로 중복 지급을 막는다.

## Vehicle SDK 후보 분류 (초기 설계)

미션을 위해 운전 중 차량 조작을 요구하거나, 경고가 없다는 이유로 보상하지 않는다. 완료가 유효한 읽기 결과로 증명되지 않으면 완료·보상을 비활성 상태로 둔다. 조회 진입은 테스트할 수 있게 제공한다.

| SDK 도메인 | 권장 주기·역할 | 제안 미션 | 판단 |
| --- | --- | --- | --- |
| Door | 일일 | 운전석 문 닫힘 확인 | 읽기 전용. `ROW_1_LEFT` Door position으로 닫힘 판정. 잠금·도어 직접 제어 API는 호출하지 않음 |
| Window | 한 번만 | 바람 느끼기 | 기존 에뮬레이터 보정 값에 한정해 사용. 차종 일반화 전 실차 검증 |
| Odometer | 주간·기억 | 함께한 이동 돌아보기 | 현재 트립 거리/시간 capability와 트립 경계가 확인된 뒤 사용. 거리 목표나 장거리 보상은 두지 않음 |
| Tire | 주간 정보형 | 타이어 상태 안내 보기 | 지원·권한이 확인된 정보 안내만. 차량 점검을 대체하지 않음 |
| EvBattery | 주간·EV 전용 | 충전 상태 돌아보기 | 충전 중 상태·데이터 의미가 검증된 차량에서만 노출 |
| HVAC | 선택형·정차 | 실내 온도 살펴보기 | 조회만 사용. 온도 조절을 강요하거나 제어 API를 호출하지 않음 |
| Light | 한 번만·정차 | 실내 조명 알아보기 | 실내 조명 구분과 읽기 지원 확인 후 사용 |
| Wiper | 정보형 | 와이퍼 상태 알아보기 | 비·눈 등 실제 상황에서만 정보 제공. 미션 때문에 작동하지 않도록 함 |
| Seat | 선택형·정차 | 내 자리 확인하기 | 조회 지원 확인. 조정은 사용자가 차량 조작부에서 정차 중 직접 할 때만 안내 |
| Steeringwheel | 정보형·정차 | 핸들 설정 살펴보기 | 열선·각도 데이터 지원과 의미 확인 전 비활성 |
| Brake | 정보형 | 차량 상태 안내 | 브레이크 조작·급제동을 미션화하지 않음 |
| TurnSignal | 정보형 | 방향 지시등 안내 | 방향 지시등 사용 횟수나 조작을 보상하지 않음 |
| SideMirror | 후속 정보형 | 미러 기능 살펴보기 | 상태 조회와 권한 확인 후 검토 |
| Display | 펫 설정 보조 | 차량 표시 단위 안내 | 차량 상태 미션보다 도움말에 적합 |
| Toll | 설정 보조 | 하이패스 음성 설정 안내 | 미션으로 만들기보다 설정 도움말로 분류 |
| Gear | 안전 게이트 | 주차 상태 확인 | 미션 보상보다 차량 UX 제한 게이트에 사용 |

위 분류는 API가 존재한다는 이유만으로 실차·모든 차종에서 동작한다고 보장하지 않는다. 각 속성별 `checkXXXCapabilities`, 허용된 권한, 현재 값, 콜백 해제, UX 제한, 오류 상태를 확인한 뒤 지원 차량에서만 활성화한다.

## 자동 감지와 직접 확인의 경계

앱이 활성화되어 있는 동안 차량 SDK 상태를 구독한다. 이벤트는 읽기 전용이며 차량을 직접 조작하지 않는다. 운전 중에는 화면·XP·성장 연출을 띄우지 않고, 감지한 Window 최초 달성만 메모리에 보류했다가 앱이 다시 안전한 주차·UX 허용 상태가 되면 저장한다. 앱이 종료된 동안의 상태 변화는 수집하지 않는다.

| 구분 | 미션 | 동작 |
| --- | --- | --- |
| 자동 감지 | 바람 느끼기 | Window 상태 구독으로 앞좌석 왼쪽 창문이 열린 값을 감지. 이미 열린 상태로 앱을 시작해도 현재 지원 상태를 읽어 처리할 수 있음. 주차 안전 상태에서 +10 XP 저장 |
| 자동 확인 | 운전석 문 닫힘 확인 | 안전하게 사용할 수 있는 주차 상태가 되면 운전석 Door position을 읽음. 닫힘이 확인된 날 +5 XP. 열려 있으면 상태를 구독하고, 사용자가 닫은 뒤 자동으로 다시 확인. 주간 3일 보너스 +15 XP는 기존 날짜 집계에서 자동 계산 |
| 직접 확인 유지 | 지원 확인된 차량 정보 조회 10개 | 값의 변화는 사용자가 해당 정보를 살펴봤다는 뜻이 아님. 미션 항목에서 조회·내용 확인을 시작하고 완료하도록 유지 |
| 직접 확인 유지 | 장소·목적지·음성·이동 기억 | 이름·메모·음성 확인처럼 사용자 의도가 필요한 기록이다. 앱은 수집 가능한 후보를 보여주되 동의 없이 저장하거나 XP를 지급하지 않음 |

자동 수신은 앱 세션이 살아 있고 해당 차량이 속성을 지원하며 권한이 허용된 경우에만 동작한다. 미지원·연결 해제·앱 종료 시 자동 완료를 추정하지 않는다. UX 제한 중에는 완료·보상·성장 연출을 처리하지 않고 주차 후 다시 확인한다.

## 나머지 SDK 모듈

| SDK | 제품 역할 | 미션 보상 연결 |
| --- | --- | --- |
| FusedLocation | 사용자가 동의한 장소 기억 추가 | 좌표 방문이나 운전 거리를 목표·순위로 만들지 않음. 데이터 최소 수집과 위치 접근 차단 처리가 선행돼야 함 |
| NaviHelper | 사용자가 시작한 내비게이션 경험과 선택적 도착 후 기억 연결 | 목적지 설정·경로 변경·운전 자체를 보상 조건으로 삼지 않음 |
| TextToSpeech | 주차 상태에서 펫의 짧은 반응 재생 | 미션 판정·보상 원천이 아님 |
| SpeechToText | 주차 후 음성 메모 입력 | 음성 입력 없이도 기억 저장 가능해야 함. 미션 판정·보상 원천이 아님 |
| Gleo Interface | 향후 허용된 앱 기능 호출·음성 진입 | 독립 Vehicle 미션 데이터 원천이 아님 |

SDK Overview는 Vehicle, NaviHelper, TTS, STT, FusedLocation 모듈을 구분하며, Vehicle API는 속성별 capability와 승인된 권한을 전제로 한다. 따라서 “모든 SDK를 미션으로 바꾸기”보다 각 SDK를 미션 판정, 기억 보조, 이야기 표현 중 적합한 역할에 연결한다.

## 현재 구현과 검증 경계

- 구현: `GrowthProgress`는 일일 날짜별 확인과 주간 보너스 주차를 저장하고 XP에 반영한다. 기존 단일 Window 저장 파일은 읽을 수 있도록 v4로 마이그레이션한다.
- 구현: Door 미션은 `ROW_1_LEFT` 위치 capability와 현재값만 읽어 닫힘 상태를 확인한다. Pleos Connect v2.1.0 AVD에서 해당 영역의 잠금 속성이 `ERROR_NOT_SUPPORTED_PROPERTY`를 반환해 잠금 확인은 조건에서 제외했다. 앱은 Door `set` API를 호출하지 않는다.
- 구현: Window는 최초 달성 1회만 지급한다. Door 일일 XP와 세 번의 일일 확인으로 얻는 주간 XP는 서로 다른 기간 ID로 중복을 막는다.
- 부분 확인: Virtual Console의 Door Position 신호와 앱의 운전석 위치 조회·닫힘 판정을 확인했다. 잠금은 해당 영역에서 지원되지 않아 일일 미션 조건으로 사용하지 않는다.
- 미검증/대체 구현: Odometer current trip distance는 AVD에서 `ERROR_NOT_SUPPORTED_PROPERTY`. 앱의 TOTAL 누적거리 대체 경로는 Virtual Console에서 검증되었고 주행 시간은 확인 불가로 남는다. Console의 누적거리 변경은 current trip API 지원 증거가 아니다.
- 배포 전제: Door 외의 신규 조회 권한은 아래 실제 차량 조회 미션 절에 정리했다. 앱 마켓 배포 전 Pleos 프로젝트의 승인 범위 확인은 별도로 필요하다.

## 실제 차량 조회 미션 활성화

초기 14개 후보 중 AVD에서 SDK 조회·유효값·완료 저장·최초 +5 XP까지 확인된 10개만 미션으로 노출한다. Safety·DrivingMode·Fuel은 AVD가 해당 속성을 제공하지 않았고 CarInfo는 유효 VIN 값이 없었다. 이 네 항목은 제거했으며, Virtual Console의 경고등이나 주행 가능 거리 조절 기능을 다른 SDK 속성의 지원 증거로 간주하지 않는다. 주차·UX 허용 상태에서 capability와 현재 값을 읽고 사용자가 결과를 확인하면 항목별 최초 1회 +5 XP를 지급한다. 미지원·권한 오류·값 없음·잘못된 범위·응답 시간 초과에는 보상을 지급하지 않는다.

| ID | 실제 조회 | 의미와 제한 |
| --- | --- | --- |
| odometer | CurrentDistanceDriven | 누적 km. 이전 current-trip 미지원 경로와 구분 |
| tire | LowTirePressure | 지원 바퀴별 저압 기준 kPa. PRIVATE 권한이 필요한 현재 공기압을 대신한 진단으로 표시하지 않음 |
| battery | EvBatteryStateOfCharge | 0..100% 유효 값 |
| light | CabinLightState | 현재 실내 조명 상태 |
| hvac | HvacTemperatureCurrent | 지원 좌석 영역별 실제 실내 온도 °C. 설정 온도와 구분 |
| wiper | WiperState | 지원 창문 영역별 현재 상태 |
| seat | SeatOccupancy | 지원 좌석 영역별 착석 감지 상태 |
| brake | BrakePedalStatus | 페달 상태. 성능 검사나 조작 미션 아님 |
| turn_signal | TurnSignalState | 현재 꺼짐·좌·우 상태 |
| mirror | HvacSideMirrorHeat | 지원 미러 영역별 열선 단계 |

각 조회는 12초 뒤 타임아웃되고 SDK를 해제한다. 주차 이탈·화면 이탈·앱 백그라운드 전환 시 미완료 요청을 취소한다. 결과는 조회 60초 안에만 보상 확인에 사용할 수 있고 지급 직전 주차·UX를 다시 확인한다. 보상 저장 중에는 다른 성장 기록 변경을 시작하지 않는다.

성장 저장 형식 v4는 조회 미션 완료 ID를 기존 보상과 함께 원자적으로 저장하고 v1/v2/v3 기록을 읽는다. 앞서 잘못 추가한 v3 학습 완료 ID는 차량 조회 완료로 간주하지 않으며 XP 계산에서 제외한다. 기존 Window/Door 보상은 유지한다.

추가한 조회 권한은 CAR_ENERGY, CAR_LIGHTS, CAR_SAFETY, CAR_SEATS, CAR_CLIMATE, CAR_MIRRORS다. 제어·PRIVATE 권한과 미션에 쓰지 않는 CAR_INFO 권한은 요청하지 않는다. 실제 배포 전에는 Pleos 프로젝트의 승인 범위가 이 선언과 일치하는지 확인해야 한다. 에뮬레이터에서의 성공은 실차 전 차종 지원을 의미하지 않는다.

## AVD 실행 결과 (2026-10-27)

초기 14개 후보 모두 앱 화면에서 실제 SDK 조회를 시도했다. 현재 노출하는 완료 검증 미션은 아래 10개다.

- 성공 10개: 누적 주행거리 0.0 km, 타이어 저압 기준 4바퀴 각각 137 kPa, 배터리 100%, 실내 조명 꺼짐, 실내 온도 19.1°C, 와이퍼 꺼짐, 좌석 착석 상태, 브레이크 페달 밟히지 않음, 방향지시등 꺼짐, 미러 열선 단계 0.
- 미지원 3개: 브레이크액 상태, 주행 모드, 연료 잔량은 ERROR_NOT_SUPPORTED_PROPERTY. 완료 버튼 비활성, XP 미지급을 확인했다.
- 유효값 없음 1개: 차량 식별 정보는 유효한 형식의 값이 없어 완료·XP 지급을 차단했다. 식별번호는 결과에 남기지 않았다.
- 실제 조회 10개 보상 총 +50 XP를 기존 바람 보상 +10 XP와 합산해 홈에서 Lv.4 / 60 XP 표시를 확인했다. 이미 완료한 누적 주행거리·배터리를 다시 조회했을 때 추가 보상이 없는 것도 확인했다.

### 새 미션 AVD 실행 확인

- 위치 권한을 최초 요청하고 허용한 뒤 미션 복귀·현재 위치 확인·장소 이름 저장에 성공했다. 권한 요청으로 앱이 잠시 중단될 때 입력한 장소 이름을 복원한다.
- 한마디 직접 입력과 장소 저장으로 각각 +5 XP가 지급돼 기존 60 XP에서 70 XP로 증가했다.
- 현재 내비게이션에 목적지가 없어 목적지 조회 미션이 저장·보상을 차단하는 것을 확인했다. 실제 목적지 근처 성공 판정은 목적지를 설정한 환경에서 추가 확인해야 한다.
- 음성 Locale은 ko-KR(Locale.KOREA)로 지정한다. 온디바이스 TTS 인사 재생 완료 후 STT의 마이크 준비 상태까지 확인했다. 자동 테스트에서는 발화 내용을 입력·출력·저장하지 않았으므로 실제 사용자 발화 인식 정확도와 첫 인사 보상 성공은 추가 확인 대상이다.
- 음성 엔진 오류는 발화 내용 없이 오류 종류만 로깅하며, 권한·언어·오디오·온디바이스 엔진 오류를 사용자에게 구분해 안내한다.

- AVD 도감에서 저장한 장소·한마디 2개와 전체 목록 진입을 확인했고, 앱 업데이트·재실행 후에도 70 XP와 레벨 4가 유지됐다.
- 음성 취소를 실제로 실행한 뒤 AudioService의 활성 녹음 목록에서 CAAS 녹음 세션이 사라진 것을 확인했다. 앱의 중단 표시뿐 아니라 시스템 녹음 종료까지 검증했다.

## 2026-10-29 미션 자동 감지

- 앱이 활성화되어 있을 때 앞좌석 왼쪽 창문 상태를 읽기 전용 구독한다. 열린 값이 오면 첫 바람 달성 후보를 기록하며, 운전 중에는 보상·화면 반응을 처리하지 않는다. 안전한 주차와 UX 허용 상태에서 +10 XP를 저장한다. 반복 콜백은 기존 `windCompletedAt` 중복 방지에 걸린다.
- 안전하게 사용할 수 있는 주차 상태에 들어오면 Door 일일 미션을 자동 조회한다. 운전석 문이 열려 있으면 주차 중 운전석 Door position을 구독해 사용자가 차량 조작부에서 닫은 뒤 자동 재조회한다. 닫힘 확인 시 +5 XP를 저장하며, 주간 3일 보너스는 기존 누적 규칙을 따른다. 잠금 상태는 현재 Pleos Connect v2.1.0 AVD에서 해당 영역의 capability가 지원되지 않아 판정에서 제외했다.
- 10개 차량 정보 조회는 상태 값이 존재하거나 변했다는 이유만으로 사용자가 정보를 확인했다고 간주하지 않아 수동 시작·확인을 유지한다. 장소·목적지·음성·이동 기록도 저장 의도가 필요한 단계는 유지한다.
- 앱 빌드·전체 76개 단위 테스트·Pleos Connect v2.1.0 AVD 설치와 실행은 확인했다. 자동 Window/Door callback으로 보상이 실제 반영되는 시연은 이번 검증에서 수행하지 않았다. 앱 활성 중에만 수신하며, 차종별 capability·권한이 없으면 자동 완료하지 않는다.

## 2026-10-30 펫 반응

자동 창문·문단속 보상 저장 후 홈 펫 위에 5.5초간 짧은 말풍선을 표시한다. 주차·UX 허용 상태에서만 표시하고, 설정의 ‘동료 반응 음성’을 켜면 Pleos 온디바이스 TTS로 읽는다. 음성 기본값은 꺼짐이며 홈 이탈·주차 제한 시 재생을 정리한다. 디버그 빌드 확인. 실제 차량 이벤트와 음성 출력의 통합 시연은 추가 확인 대상이다.

## 2026-10-30 Virtual Console 재확인

Virtual Console이 현재 실행 중인 Pleos Connect Emulator에 신호를 넣는 공식 웹 테스트 도구임을 확인했다. 앱은 `http://127.0.0.1:8088/`에서 도어, 창문, 누적 거리 등 지원 신호를 받을 수 있다. Console의 상태 제어가 SDK capability 지원을 보장하지는 않는다. 이번 앱 삭제·초기 설치 검증에서 Window 앞좌석 왼쪽 값을 바꿔 자동 미션 +10 XP와 레벨업을 확인했고, Door 운전석 position `0`으로 일일 +5 XP 및 주간 1/3 진행을 확인했다. 운전석 잠금 속성은 `ERROR_NOT_SUPPORTED_PROPERTY`라 미션에서 사용하지 않는다.

- 음성 서비스 준비·TTS 재생과 취소 정리는 확인했지만, 실제 발화 인식·첫 인사 완료 보상은 확인이 남아 있다.
- Vehicle 조회 capability가 차종마다 다를 수 있다. 현재 차량 목록은 AVD 완료 확인 목록이며, 실제 차량/차종 지원을 주장하지 않는다. release 전 capability 기반 안내를 검증한다.
- 미션 UI에서 완료로 보이는 기존 저장 상태는 새 사용자 end-to-end 검증을 대신하지 않는다. 시연 데이터를 조정했다면 날짜 조정 사실을 공개한다.
- 보상은 읽기 전용 차량 상태나 사용자가 선택한 기억 저장으로 판정한다. 차량 제어 명령·주행량 경쟁·운전 중 앱 사용을 요구하지 않는다.

## 2026-11-05 반복 미션 변경

창문 경험은 첫 달성 +10 XP, 이후 날짜마다 한 번 +2 XP로 변경했다. 유효한 앞좌석 왼쪽 창문 열림을 읽고 주차·UX 허용을 재확인한 뒤 저장한다. 환기 효과를 측정하거나 창문을 직접 제어하는 기능은 아니다. 첫 바람 기억과 삭제 상태는 그대로 유지한다. 도어 닫힘 확인은 기존 하루 +5 XP, 주간 서로 다른 3일 +15 XP를 유지한다. 장소·목적지·한마디는 기존 일일 미션이다. 차량 기능 조회 10종과 첫 음성 인사는 발견·학습 목적의 최초 1회 보상을 유지한다. 창문 닫힘은 이번 범위에서 별도 보상으로 추가하지 않았다.

성장 파일은 버전 6에 반복 창문 날짜를 추가하며 버전 1~5의 보상과 기억을 복원한다. 날짜는 현재 기기 시간대를 사용한다. 서버 시간 기반 부정 방지는 서버 이전 시 검토한다.
