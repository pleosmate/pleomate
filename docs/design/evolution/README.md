# 캐릭터 성장 외형 — Lv.1 → Lv.5 → Lv.15

6종 동료 각각에 3단계 외형을 적용했다. Lv.1은 기존 원화를 유지하고 Lv.5·Lv.15 원화 12개를 새로 제작했다.

| 동료 | Lv.1 | Lv.5 | Lv.15 |
|---|---|---|---|
| 곰 | 기본 크림 곰 | 꿀빛 초승달 배 무늬·작은 볼 털 | 풍성한 볼 털·금빛 별 배 무늬 |
| 토끼 | 기본 아이보리 토끼 | 굽은 귀 끝·가슴 털·잎 무늬 | 금빛 귀 끝·풍성한 털·꽃 무늬 |
| 픽셀 여행자 | 기본 여행자 | 어깨 망토·잎 핀·금빛 부츠 버클 | 짙은 녹색 코트·금색 장식·나침반 브로치 |
| 구름 요정 | 기본 구름·별 | 푸른 구름결·커진 별 | 풍성한 구름 소용돌이·별 3개 |
| 씨앗 정령 | 새싹 | 꽃봉오리·밝은 배 무늬 | 꽃이 핀 새싹·풍성한 잎 |
| 미니 자동차 로봇 | 기본 파란 차체 | 어깨 패널·가슴 표시등 | 진한 보호 패널·금색 범퍼·확장 바퀴 발 |

## 적용

- Lv.1~4는 첫 외형, Lv.5~14는 두 번째 외형, Lv.15 이상은 세 번째 외형. 기준: `PetAppearance.kt`.
- 홈·동료 선택·하단 동료 아이콘은 실제 성장 레벨의 외형을 표시한다. 저장된 캐릭터 ID와 XP는 바꾸지 않는다.
- 꾸미기에서 현재 / Lv.1 / Lv.5 / Lv.15 외형 및 모션을 미리 볼 수 있다. 미리보기는 성장·보상 기록을 변경하지 않는다.
- 모션 해금은 기존 Lv.1~5 유지. 외형 변화와 별도다.
- 곰·토끼: 각 성장 단계에서 몸 6방향·웃음·팔·발을 같은 atlas로 렌더링. 귀가 잘리지 않게 투명 행 간격을 찾아 분리한다. 스카프·리본은 몸 비율에 맞춘 기존 좌표로 함께 움직인다.
- 도트 4종: 성장 단계별 기본·웃음·인사·갸웃, 점프 준비/공중/착지·축하, 걷기 4프레임·달리기 4프레임. 좌우 이동(왼쪽은 반전)이다. 여행자의 Lv.1은 기존 8셀 원화를 유지하며 이동은 기존 좌우 걷기를 공유한다. Lv.5/15부터 16셀 원화로 별도 달리기·점프 자세를 사용한다.
- 주차 중 미리보기만 제공하며 Pleos 주행 제한은 유지한다.
- 새 원화 경로: `app/src/main/assets/pets/evolution/{bear,rabbit,pixel,cloud,seed,rover}-lv{5,15}.png`.
- 제작 방식: built-in image_gen, 투명 배경, 기존 캐릭터 원화를 정체성 참고 이미지로 제공했다.

## 검증

- 외형 단계 경계·성장 명칭·기존 모션 단위 테스트 18개 통과.
- Pleos Connect v2.1.0 AVD의 `PetEvolutionRenderTest` 통과. 6종×3단계에 대해 기본, 표정/점프 15조합, 방향별 걷기/달리기 48조합, 의상 2조합으로 총 1,188회 렌더링했다. 각 단계가 다른 이미지를 사용하고 화면 경계를 벗어나지 않는지 확인했다.
- Lv.5 여행자 점프 프레임의 상단 잘림을 발견해 도트 렌더 영역의 머리 위 여백을 확보했다.
- 실제 렌더 비교: `comparison.png`. 순서: 곰·토끼·여행자·구름·씨앗·로봇, 왼쪽부터 Lv.1·5·15.
- 기존 `PetCollectionTest.reunionNeverInventsOrRestoresDeletedMemories`는 재회 문구가 ‘첫 바람’을 포함한다는 검증에서 실패했다. 성장 외형 변경과 무관한 기존 문구/기억 동작이며 이번 범위에서 수정하지 않았다. 전체 테스트가 모두 통과했다고 간주하지 않는다.
- 검증 전 실제 Pleos 사용자 10의 성장 기록·선택을 로컬 백업했다. 테스트의 앱 자동 삭제 방지는 유지했다.
- 검증 후 성장 저장 파일과 동료 설정 파일의 SHA-256이 백업과 각각 일치했다. XP·레벨·동료 선택은 변경되지 않았다.
- Computer Use 화면으로 실제 Lv.15 씨앗 정령의 꽃이 핀 외형과 달리기를 확인했다. 설정 버튼의 수동 클릭 검수는 컴퓨터 제어 오류로 완료하지 못했으며, 원화 렌더링 검증과 구분한다. 마지막에는 실제 Lv.1 씨앗 정령의 홈으로 복귀했다.
