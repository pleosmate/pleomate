# 동료 2.5D 표현

2026-10-29 최신 구현: 곰·토끼의 몸, 팔, 발 원화를 분리한 2.5D 리그를 홈·선택 화면·움직임 미리보기에 적용했다. 생성된 6프레임 그림을 바꿔 보여주던 달리기와 손·머리의 비트맵 변형을 교체했다.

## 표현 기준

- 몸 원화에는 팔다리가 없다. 같은 팔 원화 두 개와 발 원화 두 개를 각각 한 번씩 그린다.
- 어깨를 중심으로 팔을 회전시키고, 두 발은 반 주기 차이로 접지와 되돌아오는 동작을 반복한다. 반복 구간의 시작·끝 위치가 이어진다.
- 먼쪽 팔은 몸 뒤에, 가까운 팔은 몸 앞에 그린다. 정면은 양팔이 보이며 옆면에서는 몸에 가려 일부가 보이지 않을 수 있다.
- 달리는 동안 몸·얼굴·털 원화를 교체하지 않아 손발 개수나 얼굴 생김새가 프레임마다 달라지지 않는다.
- 호흡은 4.4초 주기, 세로 ±0.5%로 작게 움직인다. 깜빡임은 약 176ms이며 눈 부위만 바뀐다. 웃는 표정에서도 몸 윤곽은 고정한다.
- 인사와 축하는 같은 팔의 어깨 회전으로 표현하고, 갸웃하기는 작은 몸 기울기로 표현한다. 점프할 때는 몸과 손발이 함께 올라가고 접촉 그림자는 작아진다.
- 곰 달리기 주기는 960ms, 토끼는 820ms다. 방향은 정면·왼쪽·오른쪽·뒷면·앞 왼쪽·앞 오른쪽 여섯 개다.
- 비활성 화면·백그라운드·수동 제한·시스템 애니메이션 비활성화 시 움직임을 중단한다. 원화는 캐시하며 프레임마다 디코딩하지 않는다.
- 홈의 실제 속도 기반 달리기는 비활성화했다. 달리기는 설정의 꾸미기 화면에서 주차 중 미리보기로 제공한다. 주행 중 화면 표시는 DO 적용 가능 범위와 플랫폼 정책 확인·통합 검증 대기 상태다.

주관적인 자연스러움은 코드 테스트만으로 보장할 수 없다. 이번 변경의 확인 기준은 팔다리 수의 일관성, 어깨 연결, 발 접지, 몸 윤곽 고정, 주기 사이의 연속성과 실제 화면의 잘림 여부다. 사용자에게 어떤 모션이 더 호감 있게 느껴지는지 확인하는 작업은 별도로 남아 있다.

## 원화와 구현

[원화·제작 프롬프트 기록](./pet-rig.md), [모션 미리보기](./pet-running-preview.html).

- 원화: `app/src/main/assets/pets/rig/bear.png`, `rabbit.png`. 각각 1254×1254 RGBA PNG이며 두 장 합계 약 2.4MB다.
- 같은 폴더의 JSON에 몸 6방향·눈 감은 정면 몸의 영역과 눈 위치를 기록한다. 최신 손발은 별도 `bear-paws.png`, `rabbit-paws.png`에 있으며 `limbsImage`·`limbs`로 연결한다.
- `PetRigRenderer`는 원화와 앞뒤 순서를, `PetRigMotion`은 연속 주기와 손발 위치를 담당한다.
- `PetMotionView`는 기존 레벨·인사·축하 호출과 수명주기 제어를 유지한다.
- 기존 앉은 PNG와 달리기 v1/v2 시트는 제작 기록으로 보존하며 현재 펫 렌더러는 사용하지 않는다. [이전 시트 제작 기록](./pet-running-assets.md).
- Filament 화면은 debug 기술 비교용으로 유지한다. 현재 홈은 실시간 3D를 사용하지 않는다. 여섯 개 고정 시점이며 자유로운 360도 회전은 제공하지 않는다.

기존 경험치·해금·캐릭터 선택 저장 규칙을 유지한다. 별도 만렙을 두지 않고 Lv.4 이후에는 50 XP마다 레벨이 오른다. 잠긴 모션은 홈과 네이티브 뷰에서 모두 차단한다. 저장된 성장 기록을 처음 읽을 때는 레벨업 팝업을 띄우지 않는다.

곰은 인사 2.2초·갸웃 2.4초·점프 1.9초·축하 3초, 토끼는 각각 1.4초·1.7초·1.35초·2.3초다. 점프 높이는 360×300 기준 좌표에서 곰 14, 토끼 22다. 토끼 제스처에는 작은 후속 몸 회전을 더한다.

## 확인 방법과 범위

1. 다시 빌드한 MainActivity에서 선택 화면·홈의 호흡과 해금된 인사·갸웃·점프·축하를 확인한다.
2. debug ‘동료 움직임 미리보기’에서 곰·토끼와 여섯 방향을 선택한다. 수동 제한을 켜면 움직임이 중단된다.
3. 브라우저 미리보기에서 휴식·손 인사·갸웃·점프·축하·달리기를 고르고, 동작 위치 슬라이더로 한 구간씩 멈춰 볼 수 있다.
4. 테스트는 모션 해금, 저장 규칙, 주기 연속성, 두 발의 교대 접지, 손짓 후 원위치 복귀, 깜빡임 범위를 확인한다. 렌더링 취향이나 모든 사용자의 호감도를 검증하는 테스트는 아니다.

전체 단위 테스트 74개가 통과했고 디버그 APK 빌드를 확인했다. Pleos Connect v2.1.0 에뮬레이터에 설치·실행했다. 브라우저에서 정면 휴식·웃는 표정·인사와 대각선 달리기의 팔다리 연결을 확인했다. 정면 달리기에서는 팔의 앞뒤 깊이를 같은 쪽 발과 반대로 바꿔 양팔이 동시에 벌어지는 느낌을 줄였다. [실제 홈](./qa/pet-rig/home.png), [곰 대각선](./qa/pet-rig/bear-front-left.png), [토끼 대각선](./qa/pet-rig/rabbit-front-right.png), [미리보기 화면 기록](./qa/pet-rig/preview.png).

실제 속도 자동 전환은 Android Automotive `CarPropertyManager`의 `PERF_VEHICLE_SPEED`와 `pleos.car.permission.CAR_SPEED`를 사용한다. Vehicle SDK의 Trip Odometer와 분리된 입력이다. Pleos Connect 문서도 클러스터와 같은 차량 속도를 표시할 때 해당 속성 사용을 안내한다. 속도 속성을 지원하지 않거나 권한·연결 오류가 나면 정지 모션으로 안전하게 돌아간다. [Pleos Cluster Speed 안내](https://document.pleos.ai/docs/pleos-only/vehicle-app-developer-guide/vehicle-app-faq).

Pleos Connect v2.1.0 AVD에 설치해 실행은 확인했다. 다만 이 이미지에서는 앱에 `CAR_SPEED` 권한이 부여되지 않았고, 앱 프로세스에서 `PERF_VEHICLE_SPEED`가 CarPropertyManager 설정 목록에 나타나지 않아 속도 변경에 따른 달리기는 검증할 수 없었다. 현재 화면은 속도 값을 받지 못하면 정지 모션을 유지한다. 실제 차량별 속성 지원·권한 승인 상태는 대상 차량과 배포 설정에서 별도 검증해야 한다. Pleos 공개 샘플도 `CAR_SPEED` 선언을 사용하므로, 이 AVD 버전에서 권한·속성을 제공하는지 확인해야 한다. [Pleos Vehicle SDK 샘플 권한 안내](https://document.pleos.ai/docs/pleos-only/tutorial/vehicle-sdk-sample-app).


## 2026-10-31 주행 중 화면 검증과 MVP 시연 범위

Virtual Console의 D·가속 입력이 Pleos Connect v2.1.0 AVD 계기판 속도로 전달되는 것을 확인했다. 주행 상태에서는 플랫폼이 앱 위에 ‘주행 중에는 사용할 수 없습니다’ 차단 화면을 표시했다. 현재 Manifest에는 DO 선언이 없다. 속도 신호를 이용한 홈 자동 달리기는 검증 완료 기능에서 제외하고, 홈의 자동 달리기 연결을 비활성화했다. 주행 중 펫 표시와 반복 애니메이션은 Pleos 정책·카테고리·DO 적용 가능 범위를 확인한 뒤 별도로 검증한다.

달리기는 설정 → 동료 꾸미기의 ‘주차 중 달리기 미리보기’로 감상한다. 실제 주행 신호를 흉내 낸 완료나 보상으로 취급하지 않는다.

공모전 대표 시연: 주차(P) 상태에서 동료와 재회 → 지원되는 차량 미션 확인 → 펫 반응과 XP → 기억 저장 → 배지 도감 확인. 이동 경험은 지원되는 데이터와 사용자가 저장한 기억을 기반으로 주차 후 돌아본다. 앱이 종료·중단된 구간을 수집하거나 완료한 것으로 추정하지 않는다.

근거: [지역별 주행 규제 정책](https://document.pleos.ai/docs/pleos-only/vehicle-app-planning-guide/driving-restiction-policy), [주행 규제 개발 가이드](https://document.pleos.ai/docs/pleos-only/vehicle-app-developer-guide/driving-restriction-development-guide).

### 2026-11-02 공간 그래픽 개선

`PetSceneRenderer`에서 캐릭터 주변 장면을 그린다. 곰·토끼는 조명과 책이 있는 휴식 공간, 여행자는 표지판과 돌길, 씨앗은 정원, 구름은 구름과 별, 로봇은 충전기와 정비 상자를 사용한다. 레벨 5부터 보조 소품, 레벨 15부터 작은 별/빛 포인트를 추가한다. 중앙 신체와 귀·점프 영역은 비워두고 소품은 가장자리에 배치한다. 도트 캐릭터는 안티앨리어싱 없는 사각형을 사용한다. 원화와 표정 합성 경로는 변경하지 않았다. 실제 화면에서 전 캐릭터·전 모션의 시각 검수는 별도 필요하다.
