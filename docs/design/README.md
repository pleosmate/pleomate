# PleosMate 디자인 문서 안내

이 폴더에는 현재 UI/캐릭터 설계와 구현·검증 이력이 함께 있다. 날짜가 있는 실험 기록은 당시 결과로 읽고, 현재 앱 상태는 [제품 기획서](../pleos-vehicle-companion.md)와 [PRD](../pleos-vehicle-companion-prd.md)를 기준으로 한다.

2026-11-01부터 화면과 공통 UI의 실제 코드는 feature·core 패키지에 나뉘어 있다. 코드 위치와 화면 상태·수명주기는 [Android 아키텍처](../architecture.md)를 따른다.

## 현재 시각 방향

- Pleos 차량 화면에 어울리는 어두운 뉴트럴·올리브 그레이 톤과 따뜻한 아이보리 텍스트, 절제된 골드/세이지 포인트.
- 둥근 모서리와 가벼운 블러/반투명 표면을 사용하되 불필요한 중첩 카드·내부 사각 배경·강한 그림자 레이어를 피한다.
- 하단은 아이콘 중심의 플로팅 탐색, 홈·미션·도감·설정과 별도 동료 선택 버튼으로 구성한다.
- 곰·토끼는 2.5D, 픽셀 여행자·구름 요정·씨앗 정령·미니 자동차 로봇은 도트 아틀라스 표현이다.
- 주행 중 시선을 끄는 펫 모션·대화창은 제품 약속에 포함하지 않는다. 움직임은 주차 중 표현/미리보기로 관리한다.
