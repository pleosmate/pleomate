# 배지 도감

2026-10-27 · MVP Compose 구현 초안

## 목적

기억의 날짜 목록을 먼저 보여주는 대신, 동료와 쌓은 경험을 한눈에 훑는 수집형 그리드를 도감의 첫 화면으로 둔다. 배지는 작은 성취를 설명하고 다시 보고 공유하는 장치다. 배지 수집으로 추가 XP를 주거나 더 오래·자주 운전하도록 유도하지 않는다.

## 배지

| ID | 이름 | 획득 조건 | 기준 데이터 |
| --- | --- | --- | --- |
| first_companion | 첫 인연 | 곰 또는 토끼 동료를 선택 | 홈 진입 상태 |
| first_breeze | 첫 바람 | 지원되는 Window 미션 첫 완료 | `GrowthProgress.windCompletedAt` |
| level_two | 한 뼘 성장 | 레벨 2 도달 | 기존 레벨 계산 |
| first_memory | 첫 기억 | 첫 미션 기억 또는 이동 기억 생성 | 미션 완료·최초 이동 기억 저장 시각 |
| shared_journey | 함께한 길 | 이동 기억을 한 번 저장 | `JourneyArchive.firstSavedAt` |

이동·기억을 삭제해도 획득 배지는 유지한다. 이를 위해 Journey 저장 파일 v2에 최초 기억 저장 시각을 추가하고 v1 파일은 기존 저장 기억에서 값을 복원한다. 삭제된 v1 기록처럼 이전에 영구 삭제된 정보는 복원할 수 없다.

## 화면과 공유

- 2열 배지 그리드로 보여준다. 획득 배지는 선명하게, 잠긴 배지는 흐리게 표시한다.
- 잠긴 배지를 눌러도 상세가 열리고 획득 방법을 읽을 수 있다.
- 획득 상세에는 배지 그림, 이름, 설명, 획득 조건, 획득일을 보여준다.
- **자랑하기**는 Android 공유 시트로 배지 PNG와 설명 문구를 공유한다. 공유 대상은 사용자가 고른다.
- 공유 내용에 위치, 경로, 거리, 운전 시간, 차량 식별정보를 넣지 않는다. 친구 목록·프로필·랭킹은 MVP에 없다.
- 배지 그리드 아래에는 기존 첫 미션 기억과 이동 기억 화면을 계속 제공한다.

## 이미지·서체

- `app/src/main/res/drawable-nodpi/badge_*.png`: ImageGen으로 만든 512×512 투명 배지 일러스트 5종. 파란 enamel 메달과 상아·금색 테두리로 시안의 파란 포인트와 이어진다.
- UI 서체는 42dot의 [Asta Sans](https://github.com/42dot/Asta-Sans)를 사용한다. 정적 Regular·Bold TTF를 앱에 포함하고, 라이선스와 저작자 정보는 [`third_party/licenses`](../../third_party/licenses)에 보관한다.

## 제한

현재 배지 화면은 기존 로컬 저장값에서 획득 상태를 계산한다. 첫 인연은 동료 선택 뒤 홈에 진입하면 획득 처리한다. Odometer 속성은 AVD에서 지원 오류가 보고되어 함께한 길 배지는 현재 잠겨 있다. 차량 지원 전체와 실차 동작은 검증 전이다.
