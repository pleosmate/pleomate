# 첫 기억과 재회

2026-10-26 · 첫 Window 미션에서 이어지는 기억 한 건을 구현한다. 메모 편집·여정 수집·전체 도감은 후속 범위다.

## 사용 흐름

1. 바람 느끼기 완료 → 기쁜 반응과 ‘함께한 첫 바람’ 안내 → 10 XP / Lv.2와 첫 기억을 함께 확정한다.
2. 홈의 ‘함께한 기억’에 **처음 함께 바람을 느낀 날**과 실제 첫 달성 날짜를 표시한다. 메모 입력은 요구하지 않는다.
3. ‘기억 다시 보기’에서 날짜·경험 설명을 본다. 다시 보기는 경험치를 추가 지급하지 않는다.
4. 다음 실행에서는 **지난번 함께 느낀 바람, 기억나?**로 인사한다. ‘어제’ 같은 상대 시점이나 수집하지 않은 위치·날씨·거리·시간은 만들지 않는다.
5. 상세에서 ‘기억 삭제’를 선택하면 확인 안내를 표시한다. 삭제가 저장되면 카드와 재회 인사에서 제외한다. 미션 달성·레벨·10 XP는 유지하고, 창문 반복 조작으로 기억을 재생성하거나 보상을 다시 지급하지 않는다.

현재는 첫 경험 한 건만 보이므로 별도 도감 탐색이나 테마·메모 작성 화면을 추가하지 않는다. 캐릭터 변경 시에도 같은 기억과 성장을 유지한다.

## 저장·복원과 제한

- 기존 `companion-growth-v1` 파일의 첫 달성 시각을 기억의 근거로 재사용한다. 보상과 기억을 서로 다른 파일에 나누어 쓰지 않는다.
- 기존 숫자 한 줄 파일은 ‘기억 표시’ 상태로 읽는다. 업데이트 후 미션을 다시 달성할 필요가 없다.
- 새 파일은 첫 줄에 달성 시각, 둘째 줄에 `visible` 또는 `hidden`을 기록한다. 삭제는 기억의 노출 상태를 저장하며 보상 중복 방지 근거인 첫 달성 시각은 유지한다. 보안 삭제를 제공한다는 뜻은 아니다.
- 파일 쓰기·동기화·원자적 교체가 끝난 뒤 화면을 갱신한다. 저장 실패 시 기존 화면과 기록을 유지한다.
- 모든 성장 읽기·쓰기를 프로세스의 같은 저장 큐에서 순서대로 처리한다. 이전 Activity의 수락된 저장이 진행 중이면 새 Activity의 복원 읽기는 그 뒤에 실행된다.
- P 기어·UX 사용 허용이 확인될 때 기억 보기와 삭제를 허용한다. 제한 상태로 바뀌면 상세·삭제 안내를 닫는다. 확정 전 삭제 화면에서 제한되면 삭제하지 않는다. 이미 요청한 저장은 마무리한다.
- 기존 미션은 취소·백그라운드·P 해제·오류 시 시도 번호를 무효화하고 구독을 해제한다. 이전 시도의 늦은 콜백은 완료로 인정하지 않는다. 이 부분의 최신 실제 AVD 중단 시나리오는 별도 확인이 필요하다.

## 검증

- 실제 Kotlin/JUnit 바이너리로 `WindMissionTest` **15개 통과**. 기존 9개와 함께 레거시 복원, 미달성 시 기억 없음, 삭제 후 복원·재회 제외·보상 유지, 반복 열람, 삭제 저장 실패, 손상된 노출 상태를 검사했다.
- 실제 Android·AndroidX·android.car 바이너리로 main/debug 및 기존 선택 instrumentation 테스트 소스 타입 검사 통과. 임시 R 상수를 사용한 검사이며, instrumentation 테스트를 실행한 결과는 아니다.
- 새 문자열 XML 파싱 통과.
- Android Studio에서 `:app:assembleDebug` 실행 후 설치 성공을 확인했다. Pleos Connect v2.1.0 API 34에서 기존 토끼 선택·Lv.2·10 XP가 복원됐고, 2026년 10월 26일 첫 달성 날짜와 기억 카드·재회 인사를 확인했다.
- MainActivity를 다시 빌드·재실행한 뒤 토끼 선택·Lv.2·10 XP·기억 날짜·재회 인사가 그대로 유지되는 것을 한 번 더 확인했다.
- 실제 AVD에서 기억 상세 → 삭제 확인 → 취소 → 상세 → 홈 복귀를 확인했다. 사용자의 기록은 삭제하지 않았다. 삭제 확정 후 상태 복원은 단위 테스트로 검증했으며 실제 앱의 삭제 확정은 실행하지 않았다.
- P 해제·연결 중단 중 미션 중단, 야간·최소 폭, 앱 프로세스 강제 종료 직전 저장 같은 기기 시나리오는 아직 확인하지 않았다.

## 실행 확인 순서

1. Android Studio에서 MainActivity를 다시 실행한다. 이전 미션을 완료했다면 Lv.2 / 10 XP와 기억 카드가 바로 보여야 한다.
2. ‘기억 다시 보기’에서 첫 달성 날짜와 설명을 확인한다. 닫고 다시 열어도 10 XP가 유지돼야 한다.
3. 앱을 종료·재실행한 뒤 기억 카드와 기억을 활용한 인사가 나오는지 확인한다.
4. 삭제 확인에서 취소하면 카드가 유지돼야 한다. P 해제 시 안내가 닫히고 새 삭제를 요청하지 않아야 한다.
5. 삭제 동작은 지워도 되는 별도 테스트 기록에서 확인한다. 삭제·재실행 후 기본 인사로 돌아오고, 기억 없이 Lv.2 / 10 XP와 미션 완료가 유지돼야 한다.
6. 작은 창·넓은 창·야간 모드에서 카드·상세·삭제 안내의 가독성과 스크롤을 확인한다.

## 구현 위치

- `FirstMemoryCard.kt`: 첫 기억 카드, 읽기 상세, 삭제 확인.
- `MainActivity.kt`: 완료 순간과 기억 기반 재회 인사.
- `GrowthProgress.kt`: 표시 가능한 기억과 보상 규칙.
- `GrowthStore.kt`: 기존 파일 호환과 기억 노출 상태 저장.
- `CompanionSession.kt`: 순차 저장·삭제 결과 반영·실패 처리.
