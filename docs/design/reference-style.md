# 참고 화면 스타일 적용

`references/5.jpeg`의 커뮤니티 앱 홈과 `references/6.jpeg`–`13.jpeg`의 보조 화면에서 간결한 플로팅 탭·반투명 표면·레이아웃 리듬을 참고한다. 색상은 사용자가 지정한 중립적인 회색/올리브 계열로 조정했다. 이미지의 초대·채팅·모임 기능과 콘텐츠는 제품 범위에 포함하지 않는다.

## 적용 기준

- 캐릭터 화면별 어두운 뉴트럴·올리브 그레이 그라데이션. 적색/와인색은 현재 제품 테마가 아니다.
- 흰색 계열 텍스트와 얇은 밝은 테두리를 사용한 반투명 표면
- 과도하게 각지지 않는 둥근 미션·기억 카드
- 화면 좌우와 하단에서 간격을 둔 플로팅 탭 바와 분리된 원형 펫 바로가기
- 선택된 탭은 은은한 반투명 하이라이트로 표시
- 주요 버튼은 밝은 흰색 표면과 짙은 글자로 표시
- 펫, 미션, 도감의 기존 기능과 정보 구조는 유지

## 구현

Compose 공통 테마는 `MainActivity.kt`의 `CompanionTheme`에 정의한다. 현재 하단은 홈·미션·도감·설정 아이콘과 동료 선택 버튼으로 구성한다. 카드와 배지의 중첩 surface·내부 사각 배경·반복된 그림자를 피하는 것이 디자인 요구다. 실제 렌더 상태는 현재 APK 화면에서 확인해야 하며 이 문서는 참고 의도와 이력을 설명한다.

참고 캡처의 블러는 화면 뒤 콘텐츠를 흐리게 만드는 효과다. Compose 레이아웃에서 별도 blur 렌더링 없이 반투명 색과 테두리, 그림자로 유사한 유리 표면 인상을 구현한다. 최종 대비와 간격은 Pleos Connect 에뮬레이터의 실제 화면 크기에서 확인한다.
