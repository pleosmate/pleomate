# 도트 동료 3종 — 2026-10-31

기존 곰·토끼·픽셀 여행자를 유지하고 도트 구름 요정(`cloud`), 씨앗 정령(`seed`), 미니 자동차 로봇(`rover`)을 추가했다. 독자 디자인으로 제작했으며 특정 작품의 캐릭터를 참고 이미지로 제공하지 않았다.

- 이미지: `app/src/main/assets/pets/{cloud,seed,rover}-v1.png`, built-in image_gen, 투명 배경.
- 4열×4행 각 16프레임. 1행: 기본·웃음·인사·갸웃. 2행: 점프 준비·공중·착지·축하. 3행: 걷기 4프레임. 4행: 달리기 4프레임.
- 렌더링: 실제 48×48 셀 격자로 축소 후 필터 없이 확대. 오른쪽 이동 원화와 왼쪽 반전. 정면·뒤·대각선 전용 이동 원화는 없으며 요청 시 좌우 이동으로 표시한다.
- 걷기 1,100ms, 달리기 640ms 주기. 점프는 기존 시간 곡선에 맞춰 자세 변경 및 수직 이동. 웃음·인사·갸웃·점프·축하는 기존 레벨 해금과 반응 이벤트를 공유한다.
- 꾸미기 화면에서 쉬기·걷기·달리기 및 해금된 표정/동작을 직접 미리볼 수 있다. 주차 중에만 작동한다. 실제 차량 주행 중 플랫폼 제한을 해제하지 않는다.
- 새 도트 캐릭터는 전용 기본 디자인을 사용한다. 곰·토끼의 스카프/리본은 도트 위에 덧그리지 않으며 기존 선택을 보관한다. 공간 소품은 공유한다.
- 동료 선택 화면: 넓은 화면에서 3열×2행. 동료 교체 시 성장·기억·보상 기록은 기존과 같이 유지한다.

## 검증

- `assembleDebug` 성공, 모션 단위 테스트 15개 통과.
- Pleos Connect v2.1.0 AVD에서 `PixelCompanionRenderTest` 통과. 패키지 이미지로 모든 표정, 점프 3단계, 좌우 걷기와 달리기의 표시·프레임 차이를 확인했다.
- 최초 connected 테스트 종료 시 AGP 기본 동작으로 앱이 제거되어 에뮬레이터 저장 기록이 초기화됐다. 프로젝트 내 복구용 백업은 발견하지 못했다. 이후 자동 제거를 막도록 `android.injected.androidTest.leaveApksInstalledAfterRun=true`를 설정했다.
- 설정 변경 뒤 렌더링 테스트를 재실행하고 재설치 없이 MainActivity가 열리는 것을 확인했다. Computer Use로 6종 선택 화면, 구름 달리기·씨앗 좌측 걷기·로봇 달리기 표시를 확인했다.
