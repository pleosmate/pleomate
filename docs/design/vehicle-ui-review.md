# 차량 화면 디자인 재점검 — 2026-10-31

## 반영

- 공통 폰트의 고정 흰색을 제거했다. 버튼·말풍선 등 각 컴포넌트의 글자색을 따르도록 해 밝은 버튼 위 글자를 어둡게 표시한다.
- 본문 기본 크기를 16sp에서 18sp로, 작은 상태 표시는 14–16sp로 조정했다. Asta Sans를 유지한다.
- 공통 테마의 보조색과 메뉴 표면을 웜그레이·샌드 색으로 맞췄다. XP 바의 기본 보라색 트랙을 제거했다.
- 미션 아이콘 뒤 사각 배경을 제거하고 완료 도장을 72dp에서 48dp로 줄였다.
- 도감은 배지를 먼저 보여준다. 콘텐츠 폭 720dp 이상은 3열, 그보다 좁으면 2열로 배치한다. 성장 이야기는 배지 아래에서 이어진다.
- 캐릭터 선택 카드의 설명 영역 최소 높이를 맞췄다.
- 꾸미기의 성장 단계·걷기/달리기·소품 선택을 옅은 포인트 면과 체크로 표시하고 미리보기 버튼 최소 높이를 56dp로 맞췄다.

## 확인

- `./gradlew assembleDebug` 성공.
- Pleos Connect v2.1.0 AVD에 APK 업데이트 설치 성공.
- Computer Use로 홈의 버튼 글자 대비·XP 바, 미션 카드, 도감 3열과 배지 우선 배치, 캐릭터 선택 화면, 설정의 꾸미기 선택 표시를 확인했다.
- 실제 차량의 주야간 가독성·손이 닿는 거리·다른 화면 크기에서의 사용성은 별도 확인이 필요하다. 이번 확인은 시각 배치 점검이며 미션 전체 기능 회귀 검증은 포함하지 않는다.
