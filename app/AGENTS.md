# 앱 작업 지침

이 모듈은 차량 앱의 화면, 펫, 미션과 여행 규칙, SDK 연결, 차량 내 저장을 소유한다. 파트너 정산이나 서버 운영은 현재 이 모듈의 기능이 아니다.

- `feature/*/domain`은 Android·Compose·차량 SDK에 의존하지 않는다. 새 화면은 저장 파일을 직접 조작하지 않고 data 또는 session 경계를 사용한다. 현재 `ExplorationScreen`은 위치 reader와 executor의 수명을 직접 관리하는 예외이므로 취소·화면 종료·늦은 콜백 처리를 보존한다.
- `core`는 특정 feature를 참조하지 않는다. 리소스 ID는 펫 모델이 아닌 presentation에서 매핑한다.
- 미션·기억·여행 조각을 저장할 때는 주차 상태와 작업 유효기간을 다시 확인한다. 비동기 완료가 취소·화면 이탈 뒤 도착해도 보상하지 않는다.
- 성장 보상은 저장된 완료 기록에서 계산한다. 이미 지급된 보상을 별도 카운터로 중복 저장하지 않는다. 로컬 저장을 바꾸면 구버전 읽기와 실패 시 기존 파일 보존을 검사한다.
- 위치 좌표와 경로를 여행 수집 기록에 저장하지 않는다. 경계가 불확실하거나 지원하지 않는 위치는 수집하지 않는다.
- 주행 제한과 권한 거부, 지원하지 않는 차량, 오래된 위치, 저장 실패, 중복 요청을 변경 대상의 테스트에 포함한다. 실제 차량 검증이 없으면 에뮬레이터 결과와 구분한다.
- 디버그 진단 화면과 Filament 실험 코드를 릴리스에 노출하지 않는다. `app/src/debug`의 실험 코드를 제품 기능으로 취급하지 않는다.
